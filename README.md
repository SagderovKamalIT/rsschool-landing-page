# Инструкция по запуску проекта

### 1. Установка зависимостей
Откройте терминал в папке с проектом и установите сборщик **Vite** и **Sass** командой:
```bash
npm install
```

### 2. Запуск проекта в режиме разработки (Dev)
Чтобы запустить локальный сервер и начать верстать, введите в терминале:
```bash
npm run dev
```
В терминале появится ссылка (обычно `http://localhost:5173/`).  

### 3. Сборка проекта (для проверки перед сдачей)
Когда лендинг будет готов и его нужно будет скомпилировать в чистый код, выполните:
```bash
npm run build
```
Vite создаст папку **`dist/`** в корне проекта. В неё соберутся полностью оптимизированные файлы: SCSS превратится в один минифицированный (сжатый) CSS-файл, а весь JS и картинки подготовятся для загрузки на хостинг или GitHub Pages.
